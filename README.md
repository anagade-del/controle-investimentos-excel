# 📊 Controle de Investimentos com Excel

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio **"Criando uma Ferramenta de Controle de Investimentos com Excel"**, da **DIO (Digital Innovation One)**.

O objetivo foi construir uma ferramenta em Microsoft Excel para auxiliar na **simulação e análise de investimentos em Fundos Imobiliários (FIIs)**, permitindo visualizar a evolução do patrimônio, estimar dividendos e analisar diferentes cenários de investimento ao longo do tempo.

## 🎯 Objetivos

A ferramenta permite:

- Informar o valor disponível para investimento mensal;
- Definir o período de investimento;
- Trabalhar com uma taxa estimada de rendimento;
- Projetar o patrimônio acumulado;
- Estimar dividendos mensais;
- Comparar cenários de investimento para diferentes períodos;
- Distribuir os investimentos entre diferentes tipos de Fundos Imobiliários;
- Considerar diferentes perfis de investidor na composição sugerida da carteira.

## 📈 Funcionalidades Desenvolvidas

A planilha foi estruturada para facilitar a utilização e a visualização das informações.

Entre as principais funcionalidades estão:

- Simulação de investimentos com aportes mensais;
- Cálculo do patrimônio futuro;
- Estimativa de rendimentos e dividendos;
- Projeções para períodos de **2, 5, 10, 20 e 30 anos**;
- Distribuição percentual dos investimentos entre diferentes categorias de FIIs;
- Adequação da carteira conforme o perfil do investidor;
- Utilização de fórmulas financeiras e funções de busca do Excel.

## 👤 Perfis de Investidor

A ferramenta considera diferentes estratégias de distribuição dos investimentos conforme o perfil selecionado:

- Conservador;
- Moderado;
- Agressivo.

Dessa forma, a planilha permite demonstrar como diferentes perfis podem resultar em diferentes formas de distribuição dos recursos entre os tipos de Fundos Imobiliários.

## 🛠️ Recursos do Excel Utilizados

Durante o desenvolvimento foram utilizados recursos e funções do Microsoft Excel, incluindo:

- Fórmulas financeiras;
- Função de valor futuro (FV);
- Funções de busca e referência;
- VLOOKUP/PROCV;
- Referências entre planilhas;
- Cálculos percentuais;
- Formatação de dados financeiros;
- Organização de informações para apoio à tomada de decisão.

## 📂 Estrutura do Projeto

O arquivo principal deste repositório é:

`Simulador_Investimentos_Fundos_Imobiliarios_MFB INVEST.xlsx`

A pasta de trabalho contém as abas utilizadas para realizar as simulações e configurar os perfis de investimento.

## 💡 Aprendizados

A realização deste projeto permitiu aplicar conhecimentos de Excel em uma situação prática relacionada à gestão financeira e aos investimentos.

Além da utilização de fórmulas, o desafio contribuiu para desenvolver uma visão mais estruturada sobre a criação de ferramentas financeiras, organização de dados, simulação de cenários e apresentação de informações que possam auxiliar na tomada de decisão.
